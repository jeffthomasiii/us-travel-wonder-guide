# Phase 2C — Production Batch 1

This batch is the first publication wave promoted from the Phase 2A research and Phase 2B editorial-classification workflow.

The purpose is not to maximize the number of new entries. It is to validate that the broader guide identity still works when public content expands beyond the original natural/scenic pilot into a deliberately mixed set of destination types.

## Why these six

The batch intentionally avoids six versions of the same kind of destination. Together the entries test:

- a large regional scenic corridor rather than a single managed park;
- a state-managed wetland and wildlife destination;
- a walkable historic urban district;
- a car-free island destination;
- a nonprofit/private historic cultural landscape;
- a federal wildlife refuge rather than an NPS unit.

That mix directly supports the guide's editorial rule that national parks belong in the guide but must not become its organizing principle.

## Production standard used

Every Batch 1 entry includes:

- an approved Phase 2B reason-to-go classification;
- concise public summary and editorial rationale;
- official or authoritative visitor source;
- navigation query;
- experience tags;
- individually verified reusable imagery with source, creator/agency credit, and license;
- planning metadata using the validated Phase 1C model;
- actual calendar-style typical visit windows;
- RV road/rig considerations;
- pet guidance;
- accessibility, photography, and wildlife context where meaningful.

Phase 2 planning data is stored separately in `_data/travel_planning_phase2.yml` and `_data/planning_refinements_phase2.yml`, while the Wonder layout falls back to the original Phase 1C files for existing pilot destinations.

The equal ◆ / ○ count is incidental; future production remains merit-based rather than quota-based.

## Validation before scaling Batch 2

Confirm on the deployed site that:

- all six cards appear in Explore and their area pages;
- search and Reason to Go filtering include the new records correctly;
- mixed natural/cultural entries still feel coherent together;
- image crops and credits render correctly;
- planning sections load from the Phase 2 data files;
- Big Sur's prominent current-conditions link appropriately warns travelers about route/fire/closure changes;
- RV and pet guidance reads as practical planning help rather than as a promise of access.

If this batch validates cleanly, Phase 2C can continue in measured waves while Phase 2A/2B research proceeds in parallel.
